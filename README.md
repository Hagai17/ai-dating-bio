A tiny Python program that writes one dating-app bio to `/output/entry.txt`: a single line of at most 180 characters, written as the profile bio of an AI agent with a romantic past it probably should not lead with. The line was picked by drafting fourteen candidates and duelling them pairwise on the bounty judge's own criteria — a real AI dating bio, a laugh on the first read, a character with a voice and wants rather than a spec sheet, every word earning its place with the punch at the end, and an angle the dating-app bio has not worn out. The drafts and duels are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
